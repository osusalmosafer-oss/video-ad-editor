# حلقة 1: كم يبعد فعلاً؟ — شيراتون جبل الكعبة

## الحالة: نسخة تجريبية «عيّنة» (الأرقام غير حقيقية)
الملفات في `out/`: نسخة تيك توك وإنستقرام (واتساب) ونسخة فيسبوك (راسلنا على الخاص).

## ما تعبّئه من قياسك (في `project.json` ← `walk`)
| الحقل | المعنى |
|---|---|
| `walkMinutes` | دقائق المشي الفعلية (الآن 10 تجريبي) |
| `door` | الباب الذي ينتهي عنده القياس |
| `bus.available` | `true` أو `false` (false يحذف مشهد الباص، وغيّر `end` في `scenes/main.js` إلى 28.1) |
| `bus.stop` / `bus.dropoff` | أين يقف الباص وأين ينزل |
| `cta` | `whatsapp` أو `inbox` |
| `sample` | اجعله `false` لإزالة وسم «عيّنة» قبل النشر |
