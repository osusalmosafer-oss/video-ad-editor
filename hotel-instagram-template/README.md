# قالب بوستات الفنادق - أسس المسافر

قالب Instagram قابل لإعادة الاستخدام لأي فندق، عبر تغيير ملف JSON فقط دون لمس التصميم.

## الاستخدام
```
node render.js hotels/<hotel>.json post   output.png   # بوست 1080x1350
node render.js hotels/<hotel>.json story  output.png   # ستوري 1080x1920
```

## هيكل ملف بيانات الفندق (hotels/*.json)
حقول: `hotelName, roomType, pricePerNight, currency, meals, offerDate,
distanceFromHaram, hotelPhoto, hotelLogo, agencyLogo, whatsapp, location`.
أي حقل قيمته `null` يُحذف تلقائيًا من التصميم ولا يُخترع بديل له.

## الملفات
- `template.html` — القالب (HTML/CSS + خط Tajawal).
- `render.js` — يحقن بيانات JSON في القالب ويصوّره PNG عبر Playwright، ويضبط
  حجم اسم الفندق والمسافات تلقائيًا حسب طول الاسم وعدد الحقول لمنع أي تراكب.
- `hotels/doubletree-aziziyah.json` — بيانات فندق دبل تري من هيلتون العزيزية.
- `hotels/_test-*.json` — ملفات اختبار داخلية فقط (اسم طويل/قصير، سعر 2-4 خانات) للتأكد من عدم كسر القالب، ليست للنشر.
- `output/doubletree-aziziyah_post.png` و `_story.png` — التسليم النهائي.
