# مثال موشن: فضل الصلاة على النبي ﷺ ليلة الجمعة

فيديو عمودي 1080×1920 · 60 فريم · 34 ثانية · بلا صوت مولّد (نصّي + مؤثرات هادئة بلا طبول).

- `build.py` يولّد `scenes/*.js` و`timeline.json` (6 مشاهد: ليلة الجمعة ← 3 أحاديث ← الفوائد ← الصلاة الإبراهيمية المختصرة)
- النصوص ومصادرها في `facts.md`. لا صور لأحد: هلال ونجوم وزخرفة فقط.
- الرسم والصوت (من محرّك `motion/` في السكل):
  ```bash
  node motion/render.js <هذا المجلد> all --fresh
  python3 motion/audio.py <هذا المجلد> --no-bed
  ```
- لتغيير النص: عدّل `S[...]` في `build.py` ثم شغّله من جديد.
