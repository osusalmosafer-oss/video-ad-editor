# فتاوى مسموعة تفاعلية (صورة الشيخ + موجة صوت + نص يُضاء كلمة كلمة)

مشهد جاهز لأي فتوى: نقرة تشغيل متحركة ← صورة الشيخ داخل حلقة تنبض مع صوته ← اسمه وصفته ← نص الفتوى يُضاء كلمة كلمة ← شريط تشغيل بالوقت ← المصدر.

1. ضع الصوت والصورة في `assets/` (ملفاتك أنت — لا يُولَّد صوت أي شيخ).
2. عدّل `fatawa.json`: الاسم، الصفة، المصدر، `from`/`to` بالثواني من الملف، و`lines` (نص الفتوى مقسّمًا، `t` = ثانية بداية السطر داخل المقطع).
3. التشغيل:
   ```bash
   python3 fatwa.py build
   node ../../motion/render.js . all --fresh
   python3 fatwa.py mix        # يركّب صوت الشيخ → renders/final.mp4
   ```
المثال الحالي تجريبي (صوت اصطناعي وصورة بديلة) لاختبار الشكل فقط.
