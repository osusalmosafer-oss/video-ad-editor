# حزمة تدريب موظفي الحجوزات — وحدات ضيافة بمكة

حزمة تدريب وتشغيل جاهزة لفريق حجوزات يعمل عبر الواتساب: خطة تأهيل خمسة أيام، أسلوب خدمة عملاء، إجراءات دورة الحجز، سكربتات جاهزة، اعتراضات ومواقف صعبة، تمارين لعب أدوار، مؤشرات أداء، وقوالب تشغيلية.

## كيف تستخدمها

**كمدرّب آلي:** ثبّت المجلد كسكل لكلود (انسخ `booking-training` داخل مجلد السكلز)، ثم اكتب:
- «درّبني على خدمة العملاء» — درس قصير وتمرين
- «سوّ لعب أدوار، سيناريو عميل غاضب» — أنا العميل وأنت الموظف، ثم بطاقة تقييم
- «قيّم هذي المحادثة» + الصق المحادثة — درجات ونقاط تحسين
- «عميل يقول غالي، وش أرد؟» — ردّ جاهز للنسخ

**كدليل مطبوع:** اطبع `references/04_whatsapp-scripts.md` و`references/08_templates.md` وعلّقهما أمام الفريق.

## قبل الاعتماد
المواضع المكتوب فيها `[[ ]]` تحتاج تعبئة من سياسات المنشأة (الأسعار، العربون، الإلغاء، أوقات الدخول والخروج، الحساب الرسمي). وأي بند نظامي — تسجيل النزلاء، الفوترة، الرخص — **يُراجع مع الجهة المختصة قبل اعتماده**، فالحزمة تدريبية لا مرجع نظامي.
