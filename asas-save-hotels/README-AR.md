# وفّر 20–30% على فنادق مكة الفخمة

نسختان:
- `out/save-hotels-MOTION.mp4` (25 ث): موشن جرافيك خالص، أفق مكة مرسوم (جبل عمر وبرج الساعة والكعبة)، بلا لقطات.
- `out/save-hotels-FOOTAGE.mp4` (28 ث): نفس الرسوم + لقطاتك (واجهة الفندق، الطريق نحو الحرم، ساحات الحرم وبرج الساعة).

إعادة الرسم: `save.mode` في `project.json` (`motion` أو `footage`). نسخة الفيديو: ارسم بالمحرّك بوضع footage ثم `python3 compose.py <لقطتك.mp4> <الناتج.mp4>`.

⚠ «وفّر 20–30%» ادعاء من المالك. تحته «حسب الفندق والتاريخ». احتفظ بمقارنات أسعار فعلية تثبته.
