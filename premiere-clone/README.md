# استوديو الفيديو — محرّر فيديو على نمط Premiere (يعمل بالمتصفح)

ملف واحد `index.html` بدون تثبيت ولا مكتبات. افتحه في Chrome أو Edge.

## المميزات
- مكتبة وسائط (فيديو / صور / صوت) بالسحب والإفلات
- تايملاين متعدد المسارات (نص، فيديو 2، فيديو 1، صوت 1، صوت 2): تحريك، قصّ الأطراف، مغناطيس، تكبير
- قصّ (S)، حذف (Delete)، حذف وسدّ الفراغ (Shift+Delete)، نسخ (Ctrl+D)، تراجع/إعادة
- نصوص عربية: خط، لون، حدود، خلفية، حركة نبض، ظهور/اختفاء تدريجي
- خصائص المقطع: حجم، موضع، دوران، شفافية، سطوع، تباين، تشبّع، ضبابية، سرعة، مستوى صوت
- مقاسات: 9:16 · 16:9 · 1:1 · 4:5 — دقة 480/720/1080 — 24/30/60 إطار
- تصدير فيديو مع الصوت (MP4 إن دعمه المتصفح، وإلا WebM) — يتم بزمن حقيقي
- حفظ/فتح المشروع (JSON؛ تستورد الملفات الأصلية قبل الفتح)

## اختصارات
Space تشغيل · S قصّ · ←/→ إطار (مع Shift ثانية) · Home/End · Ctrl+Z / Ctrl+Shift+Z
