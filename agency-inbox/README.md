# صندوق الوكالة

تطبيق جوال وخادم يجمعان رسائل وتعليقات واتساب وإنستجرام وفيسبوك (وتيك توك ويوتيوب لاحقاً) لعملاء الوكالة في صندوق واحد.

```
agency-inbox/
  server/   خادم Node: يستقبل الويب هوك من Meta، يخزن في SQLite، ويخدم التطبيق
  app/      تطبيق Expo (React Native): الصندوق، المحادثة، الملاحظات، التقارير
```

## الحالة

| المنصة | استقبال | رد |
|---|---|---|
| واتساب (رسائل) | جاهز | جاهز، مع منع الرد الحر بعد 24 ساعة |
| إنستجرام (رسائل وتعليقات) | جاهز | جاهز |
| فيسبوك (ماسنجر وتعليقات) | جاهز | جاهز |
| يوتيوب (تعليقات) | لم يُبنَ | لم يُبنَ |
| تيك توك | لم يُبنَ | لم يُبنَ |

الاختبارات الآلية للخادم تعمل بحمولات Meta تجريبية. **لم يُجرَّب الربط مع حسابات حقيقية**، لأنه يحتاج تطبيق Meta ومراجعته. التطبيق اجتاز فحص الأنواع ولم يُشغَّل على جهاز.

## تشغيل الخادم

```bash
cd server
npm install
cp .env.example .env            # عدّل TEAM و META_VERIFY_TOKEN
cp clients.example.json clients.json
npm test
npm start
```

يبقى `DRY_RUN=1` حتى تتأكد أن كل شيء سليم: الرد يُسجَّل في الصندوق ولا يُرسل للمنصة.

## ربط Meta (واتساب وإنستجرام وفيسبوك)

1. أنشئ تطبيقاً من نوع Business في developers.facebook.com.
2. أضف المنتجات: WhatsApp، وMessenger، وInstagram.
3. اجعل عنوان الويب هوك `https://عنوان-خادمك/webhooks/meta` واستخدم نفس قيمة `META_VERIFY_TOKEN`. ضع App Secret في `META_APP_SECRET`.
4. اشترك في الحقول: `messages` (واتساب)، و`messages` و`comments` (إنستجرام)، و`messages` و`feed` (الصفحة).
5. لكل عميل: أنشئ رمز وصول دائم (System User) وضعه مع المعرّفات في `clients.json`.
6. لخدمة عملاء ليسوا حساباتك، يلزم اجتياز App Review لصلاحيات الرسائل والتعليقات.

## تشغيل التطبيق

```bash
cd app
npm install
npx expo start
```

افتح التطبيق بـ Expo Go، أدخل عنوان الخادم ورمز الدخول (رمز كل عضو من `TEAM`).
الخادم يلزمه عنوان HTTPS عام (للويب هوك وللجوال). للتجربة المحلية يمكن استخدام نفق مثل cloudflared.

## ما فيه

- فلترة بالمنصة والنوع والعميل والحالة، و"مسندة لي"، وبحث.
- إسناد المحادثة لعضو، وحالات جديد/قيد المتابعة/منتهي. وصول رسالة جديدة يعيد المحادثة المنتهية إلى "جديد".
- ملاحظات داخلية داخل المحادثة لا تُرسل للعميل.
- تنبيه "متأخر" عندما ينتظر العميل أكثر من `OVERDUE_MINUTES`.
- تقرير: عدد المحادثات، متوسط زمن أول رد، التوزيع بالمنصة والعميل، وردود كل عضو.

## الخطوات القادمة

1. تعليقات يوتيوب (Data API مع OAuth لكل قناة، بجلب دوري).
2. تيك توك بعد التحقق مما تتيحه واجهاتهم لحساباتكم.
3. إشعارات دفع للجوال عند وصول رسالة أو تأخر الرد (الآن التحديث كل 10 ثوانٍ والتطبيق مفتوح).
4. نشر الخادم (مثلاً على Render) مع قرص دائم لقاعدة البيانات.
5. صور ومرفقات، وقوالب واتساب المعتمدة للرد بعد 24 ساعة.
