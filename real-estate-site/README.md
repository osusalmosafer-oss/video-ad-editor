# موقع العروض العقارية (أوج — تجريبي)

موقع لتخزين العروض العقارية (أراضٍ وغيرها) بكل تفاصيلها وصورها وفيديوهاتها التسويقية، وإرسال العرض الكامل للعميل برابط واحد.

## المزايا
- **العروض**: العنوان، النوع، المدينة والحي، رابط الموقع/الإحداثيات (خريطة مضمنة)، المساحة، السعر، **سعر المتر (تلقائي)**، نوع الصك، عرض الشارع، الواجهة، الوصف، المميزات.
- **صور + فيديو تسويقي** لكل عرض (يُحفظ على الموقع ويُشغَّل مباشرة).
- **رابط خاص لكل عرض** يُرسل للعميل، ويمكن جعل العرض **خاصًا بالرابط فقط** (لا يظهر في الصفحة الرئيسية).
- **إرسال للعميل**: رسالة واتساب جاهزة (قابلة للتعديل) برابط العرض، أو نسخ الرابط.
- **نسخة PDF/طباعة** مرتبة بهوية الشركة لكل عرض.
- **استفسارات العملاء**: نموذج في صفحة العرض يحفظ العميل، ومتابعة حالته (جديد، تم التواصل، زيارة، تفاوض، تم البيع، ملغي) مع ملاحظات، وتصدير CSV لـExcel.
- **حالة العرض** (متاح / محجوز / مباع) وعدّاد **مشاهدات** لكل عرض.
- حقل **رقم ترخيص الإعلان** يظهر في العرض والـPDF والرسالة، ورقم **ترخيص الهيئة العامة للعقار** في التذييل.
- بحث وفلترة (المدينة، النوع، السعر) في الصفحة الرئيسية، ويعمل على الجوال.

## التشغيل
يتطلب Node.js 22.5 أو أحدث.
```bash
cd real-estate-site
npm install
ADMIN_PASSWORD='كلمة-مرور-قوية' WHATSAPP=9665XXXXXXXX FAL_LICENSE=رقم_الترخيص npm start
```
- الموقع: `http://localhost:3000` — الإدارة: `/admin`

## الإعدادات (متغيرات بيئة)
| المتغير | الوصف | الافتراضي |
|---|---|---|
| `ADMIN_PASSWORD` | كلمة مرور الإدارة (**غيّرها**) | `admin123` |
| `BRAND_NAME` / `BRAND_TAGLINE` | الاسم والعبارة | `أوج` / `للتسويق العقاري` |
| `WHATSAPP` | رقم واتساب المنشأة بصيغة دولية | `966500000000` |
| `FAL_LICENSE` | رقم ترخيص الهيئة العامة للعقار | — |
| `BASE_URL` | رابط الموقع النهائي (لروابط العروض المرسلة) | تلقائي |
| `DATA_DIR` | مكان قاعدة البيانات والملفات المرفوعة | `./data` |
| `PORT` | المنفذ | `3000` |

## النشر على Render
الملف `render.yaml` (في جذر المستودع) يجهّز كل شيء: خدمة ويب Node + قرص دائم 10GB لحفظ العروض والصور والفيديو.

1. أنشئ حسابًا في render.com وربطه بحساب GitHub.
2. **New → Blueprint** ثم اختر المستودع `video-ad-editor` والفرع الذي فيه الملف.
3. أدخل القيم المطلوبة: `ADMIN_PASSWORD` (قوية) و`WHATSAPP` (مثل `9665XXXXXXXX`) و`FAL_LICENSE`، واترك `BASE_URL` فارغًا الآن.
4. اضغط **Apply**، وبعد دقائق يظهر رابط مثل `https://awj-real-estate.onrender.com`.
5. لربط دومينك: **Settings → Custom Domains**، ثم ضع الرابط النهائي في `BASE_URL` (ليستعمله واتساب وملف الـPDF).

ملاحظات مهمة:
- **القرص الدائم لا يعمل في الخطة المجانية**، لذلك الخطة `starter` (نحو 7$ شهريًا + تكلفة القرص). بدون القرص تضيع البيانات عند كل إعادة نشر.
- القرص يربط الخدمة بنسخة واحدة فقط، ويسبب انقطاعًا قصيرًا عند كل نشر جديد.
- أنشئ نسخة احتياطية دورية: حمّل `leads.csv` من لوحة الإدارة، ويمكن أخذ لقطة (Snapshot) للقرص من Render.
- الأسعار والخطط تتغير، فراجع صفحة التسعير في Render قبل الإنشاء.
- لأي استضافة أخرى: شغّل `npm start` ووجّه `DATA_DIR` لمجلد دائم.

## الهوية
ملفات الشعار التجريبية في `public/brand/` (مقصوصة من تصميم الهوية التجريبية). استبدلها بالملفات النهائية بنفس الأسماء عند اعتماد الهوية.

## ملاحظات
- النسخة تجريبية: لا يوجد حساب لأكثر من مدير واحد، وحجم الفيديو الأقصى 700MB.
- خريطة الموقع المضمنة تتطلب إدخال الإحداثيات؛ يكفي رابط خرائط جوجل لزر «فتح الموقع».
