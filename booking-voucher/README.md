# مولّد ملفات الحجز — أسس المسافر

```
npm i playwright            # مرة واحدة (أو اضبط PLAYWRIGHT_PATH)
node make_voucher.mjs data.json [out.pdf]
```

- `sample.json` نموذج للبيانات (عميل، إقامات متعددة، دفعات، خصم، ملاحظات).
- `agency.json` بيانات الوكالة (أضف الهاتف والسجل التجاري والرقم الضريبي لتظهر في الترويسة).
- `terms.json` الشروط والأحكام (قابلة للتعديل؛ أو ضع `terms` داخل ملف الحجز نفسه).
- إذا لم يُذكر `bookingNo` يُولَّد تلقائيًا (WO00016 …) من `counter.json`.
- `vatMode`: `exclusive` (السعر قبل الضريبة) | `inclusive` (شامل) | `none`. النسبة الافتراضية 15%.
- `"showPrices": false` يُخفي القسم المالي (نسخة العميل بدون أسعار).
- الحسابات تتم بالهللات كأعداد صحيحة؛ عدد الليالي يُحسب من التواريخ (DD/MM/YYYY).
