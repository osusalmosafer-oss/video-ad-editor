# نظام إدارة ومتابعة طلبات استلام التبرعات

تطبيق ويب عربي (RTL) يعمل كتطبيق على أندرويد (PWA) — موظف يسجّل الطلبات، وسائق يستلمها، والمزامنة فورية.

## التشغيل
```bash
npm install
SEED_DEMO=1 npm start      # حسابات تجريبية: admin/admin123 ، employee/employee123 ، driver/driver123
npm test                   # 28 اختباراً للصلاحيات والتدفق
```
بدون `SEED_DEMO` تُولَّد كلمات مرور عشوائية وتُطبع في السجل وتُحفظ في `data/initial-credentials.txt`
(أو حدّدها عبر `ADMIN_PASSWORD` و`EMPLOYEE_PASSWORD` و`DRIVER_PASSWORD`).

متغيرات: `PORT` ، `DATA_DIR` (مجلد قاعدة البيانات SQLite — اجعله قرصاً دائماً عند النشر) ، `TZ` (الافتراضي Asia/Riyadh).

## على أندرويد
افتح الرابط في Chrome ← ⋮ ← «تثبيت التطبيق». يلزم HTTPS عند النشر ليعمل التثبيت وإشعارات الجهاز.

## حدود معروفة
- الإشعارات تصل لحظياً والتطبيق مفتوح (أو في الخلفية قصيراً) مع صوت واهتزاز؛ الإشعار والتطبيق مغلق تماماً يحتاج Web Push/FCM (غير مُضمَّن).
- تصدير PDF عبر نافذة الطباعة («حفظ كـ PDF»)؛ تصدير Excel حقيقي (.xlsx).
