## المؤثرات الصوتية — `sfx.py`

مركّبة بالكود (بلا ملفات جاهزة)، و**مستواها يُقاس لا يُخمَّن**:

الخلفية هنا شارع مفتوح بهواء وباصات، متوسطها ‎-17 dB — والمؤثر بمستوى ثابت يُطمَس تحتها تماماً.
فصار `sfx.py` يقيس طاقة الخلفية في نافذة 70 مللي عند كل مؤثر، ويحسب كسبه ليعلو عليها **‎+3.5 dB**
بعد **خفض لحظي للأصلي** (40٪ عادةً، و62٪ لو كان يتكلم بصوت عالٍ) بمنحدر ناعم 40 مللي.
والنقرة نفسها مائلة للحدّة (نقرة + زقزقة 1.5→3.4 كيلوهرتز) لتمرّ فوق الهواء منخفض التردّد،
وتوضع **في السكتة الصغيرة قبل الكلمة** لا فوقها.

| المؤثر | الثانية | الخلفية | الكسب |
|---|---|---|---|
| خريطة جبل عمر | 16.84 | ‎-28.0 dB | 0.173 |
| خريطة العزيزية | 24.38 | ‎-12.6 dB | 0.340 (بلغ السقف) |
| مربّع جبل عمر | 33.18 | ‎-24.4 dB | 0.261 |
| مربّع العزيزية | 34.27 | ‎-22.9 dB | 0.308 |

**10 لحظات / 42.4 ث = 14.2 بالدقيقة** — تحت سقف الـ15 بقواعد السكل.
⚠️ **ذروة المؤثرات ‎-9.4 dBFS، أعلى من سقف الـ‎-18 المذكور بالقواعد** — وهذا مقصود:
مع هذه الخلفية، الالتزام بـ‎-18 يعني مؤثرات لا تُسمع أصلاً (وهو ما بلّغ عنه المستخدم).
لو صُوّر بمكان هادئ، أرجِع السقف.

## إعادة البناء

```bash
# المتطلبات: ffmpeg · node · python3 (numpy, pillow) · كروم/كروميوم · puppeteer-core
export CHROME_PATH=/path/to/chrome
cp <الفيديو الأصلي> src.mp4
mkdir -p vfr && ffmpeg -v error -i src.mp4 -vf "fps=30,scale=1080:1920:flags=lanczos" -q:v 3 -y vfr/%05d.jpg
# الخطوط: Tajawal من Google Fonts إلى fonts/Tajawal-{400,500,700,800,900}.ttf
python3 sfx.py                 # ← sfx.wav
WORKERS=4 node render.js all   # ← out/%05d.jpg  (1296 فريم)
bash encode.sh                 # ← ad-final.mp4
bash master.sh                 # ← ad-master.mp4  (‎-14 LUFS)
```

معاينة قبل الرسم الكامل: `node render.js preview 6.5 12.4 21.9 36.6`
إعادة نافذة واحدة بعد تعديل مشهد: `node render.js range 37.40 43.20`

## ⚠️ عن دقّة التوقيت

النص جاء من صاحب المحتوى جملةً جملة (تنزيل موديل وِسبر محجوب بجلسة السحابة، فما صار تفريغ آلي).
**حدود الجُمل مثبّتة على قطعات المصدر المكتشفة**، وداخل كل جملة تُوزّع الكلمات بالتناسب مع طول كل كلمة
في `captions.py` — يعني الانزياح داخل الجملة الواحدة قد يصل لجزء من الثانية، وحدودها مضبوطة.
لضبط أي جملة: عدّل `SENT` في `captions.py` ثم `python3 captions.py` و`node render.js range <من> <إلى>`.
ومع تفريغ بتوقيت الكلمة (الخطوة 4 بالسكل) يصير الكابشن مضبوطاً كلمةً كلمة.
