## الإيقاع

عشر نبضات في `plan.js → BEATS`، كل نبضة = **زوم بانش** سريع (‎1.085×‎ يرتد خلال 0.42 ث)،
وأربع منها تحمل **كشيدة زرقاء مائلة** تمرّ بالشاشة خلال 0.36 ث بلون التمييز.
النبضات: `6.25 · 11.00 · 15.60 · 17.90 · 20.80 · 25.40 · 29.20 · 32.40 · 34.90 · 37.60`

## المؤثرات الصوتية — `sfx.py`

مركّبة بالكود (بلا ملفات جاهزة): كشيدة صاعدة/هابطة · طَرْق خفيف عند ظهور الكروت · دَقّة عند كرت النهاية · تنبيه «انتبه».
**10 أحداث / 43.2 ث = 13.9 بالدقيقة** — تحت سقف الـ15 بقواعد السكل، والذروة تحت ‎-18 dBFS.

## المنطقة الآمنة

كل الرسم خارج مناطق أزرار انستقرام: أعلى 150 بكسل · أسفل 300 بكسل · شريط اليمين 180 بكسل بين y‏ 1100 و1750.
شريط التقدّم خط 6 بكسل عند y‏ 1601 (خط بلا نص).

## إعادة البناء

```bash
# المتطلبات: ffmpeg · node · python3 (numpy, pillow) · كروم/كروميوم · puppeteer-core
export CHROME_PATH=/path/to/chrome
cp <الفيديو الأصلي> src.mp4
mkdir -p vfr && ffmpeg -v error -i src.mp4 -vf "fps=30,scale=1080:1920:flags=lanczos" -q:v 3 -y vfr/%05d.jpg
# الخطوط: Tajawal من Google Fonts إلى fonts/Tajawal-{400,500,700,800,900}.ttf
python3 sfx.py                 # ← sfx.wav
WORKERS=4 node render.js all   # ← out/%05d.jpg  (1296 فريم)
bash encode.sh                 # ← ad-final.mp4
bash master.sh                 # ← ad-master.mp4  (‎-14 LUFS)
```

معاينة قبل الرسم الكامل: `node render.js preview 6.5 12.4 21.9 36.6`
إعادة نافذة واحدة بعد تعديل مشهد: `node render.js range 37.40 43.20`

## ⚠️ التوقيتات مبنية على الصورة لا على الصوت

الجلسة اللي بُني فيها هذا الإعلان كانت بالسحابة، وتنزيل موديل وِسبر محجوب فيها،
فما صار تفريغ للكلام. **توقيتات «انتبه» والخريطتين وإشارتَي الحجز مستنتجة من حركة اليد بالفيديو**
(اللوحة تظهر 9-10 ث و19-20 ث، والإشارتان الأخيرتان 33 ث و36 ث).
لضبطها على الكلام فعلياً: عدّل الأرقام في `plan.js` ثم `node render.js all --force`.
ومع التفريغ يصير ممكن إضافة كابشن عربي متزامن و`.srt` (الخطوات 4-5 و11 بالسكل).
