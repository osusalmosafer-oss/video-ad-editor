# عبودي وصهيب 🎮 (على طريقة كراش)

لعبة جري جانبية على طريقة Crash Bandicoot، بطلها عبودي بجسمه الكامل (مقصوص من صوره)، وصور وجهه تظهر في الشاشة وتتغير حسب اللي يصير.

- افتح `index.html` بأي متصفح — ملف واحد بدون تثبيت. الأفضل الجوال بالعرض.
- ⬆️ قفز (مرتين = قفزة مزدوجة) · 🌀 دوران (يكسّر الصناديق ويقتل السلاطعين).
- كيبورد: مسطرة المسافة / السهم فوق = قفز، X أو Z = دوران.
- 📦 صناديق (فاكهة) · ❓ فاكهة كثير · 🎭 قناع أكو أكو (٣ أقنعة = لا يُقهر) · 🟢 صندوق نطّاط · 🧨 TNT (اقفز عليه وابتعد).
- ٣ حيوات، وكل ١٠٠ فاكهة 🍑 = حياة جديدة.

- ٥ مستويات (الصالة، غرفة الأولاد، المطبخ، ليل النجوم، سطح الغروب) وبوابة نهاية بكل مستوى.
- صهيب معه بجسمه الحقيقي: يتبعه، يجمّع الفاكهة، وينقذه مرة وحدة من الحفرة بكل مستوى.
- بدون موسيقى؛ أصوات خطوات وقفز وتفاعل، وتعليق صوتي عربي إذا الجهاز يدعمه.
