# لعبة عبودي 🎮

لعبة جري مسلّية (3 مسارات) بطلها عبودي — وجهه من صوره الثلاث يتغيّر حسب اللي يصير (مبتسم، مضحك، زعلان).

- افتح `index.html` بأي متصفح (جوال أو كمبيوتر) — ملف واحد بدون تثبيت.
- جوال: اسحب يمين/يسار للتحرك، اسحب لفوق أو اضغط بالنص للقفز.
- كيبورد: الأسهم + مسطرة المسافة.
- جمّع 🍦🍬🍭 والبالونات 🎈 (تحتاج قفزة)، خذ ⭐ للقوة السحرية و❤️ لحياة زيادة، وابتعد عن الألعاب 🚗🧱🧸.
