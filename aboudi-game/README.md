# عبودي وصهيب 🎮

تحدي بين الأخوين على شاشة وحدة: **عبودي تحت** و**صهيب فوق (مقلوب)** — كل واحد يتحكم بأزراره في جهته. الشخصيتين بجسمهم الحقيقي من الصور.

## المراحل
1. **كراش 🏃** — جري جانبي: اقفز فوق الحفر، كسّر الصناديق بالدوران 🌀، جمّع 🍑، أقنعة أكو أكو 🎭 (٣ = لا يُقهر)، TNT 🧨 وسلاطعين 🦀.
2. **سوبرمان 🦸** — طيران بعباءة حمراء: تحرّك فوق/تحت لتفادي الطيور والغيوم والأبراج والصواريخ، جمّع النجوم ⭐ والحلقات ⭕ والبرق ⚡.
3. **مطر الحلويات 🍭** (مرحلة مبتكرة) — اصطد الحلويات بالسلة 🧺 واهرب من 🌶️🧨🪨. كل ٥ حلويات متتالية ترسل فلفل لخصمك! النجمة 🌟 تكبّر السلة.

الفائز بكل مرحلة من يجمع نقاط أكثر (الأول يوصل خط النهاية ياخذ مكافأة)، وفي الآخر نتيجة نهائية.

## التشغيل
افتح `index.html` بأي متصفح. جوال/تابلت (ضعه على الطاولة بين اللاعبين) أو كمبيوتر. «لاعب واحد» أيضًا متاح.
