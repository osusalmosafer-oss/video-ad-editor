# عيّنة «الكلمة المفتاحية» (نسخة تجريبية)

> **المعتمد: النمط ب** (مستطيل أزرق). قرار المالك 7 أكتوبر 2026. النمط أ للمقارنة فقط.

فيديو 20 ثانية، 1080x1920، بهوية أسس المسافر. يجرّب:
- **بطاقة السؤال** (تعليق حقيقي بلا اسم) في أول ثانيتين.
- **نمط أ:** كلمة كبيرة بيضاء مع خط أزرق (كلمة إلى 3 كلمات).
- **نمط ب:** كلمة داخل مستطيل أزرق مع ظل خفيف.
- **كابشن** سفلي بنفس قالب الأداة، **شريط تقدم** أزرق، **كرت نهاية** بالشعار.
- **مؤثرات صوتية هادئة** مولَّدة بالكود، 5 أحداث فقط (15 في الدقيقة)، الذروة -18 dBFS:

| الثانية | المؤثر | يرتبط بـ |
|---|---|---|
| 3.2 | نقرة خفيفة | ظهور الكلمة الأولى |
| 6.6 | صوت صاعد قصير (0.9 ثانية) | التمهيد للجواب |
| 7.5 | نغمة تأكيد ناعمة | الجواب «أحياناً يسمحون» |
| 11.5 | نقرة خفيفة | التنبيه «تأكد قبل لا تروح» |
| 14.5 | نقرتا كاميرا مع وميض 10% | «المدخل» |

المربع «لقطتك هنا» مكان فيديو المتحدث الحقيقي. لا يوجد صوت كلام في العيّنة.

## التشغيل (ويندوز)
`npm i playwright-core` ثم `node build-demo.js --out demo.mp4`. يحتاج `ffmpeg` في PATH و`python`.

## قواعد
لا كاشير ولا ضربات معدنية ولا مقاطع ترند. المؤثر مرتبط بلحظة لها معنى فقط.
